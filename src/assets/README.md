# Project screenshots

Drop project images here, then `import` them in `src/components/Projects.astro`
and pass to `<Image />` — Astro resizes and converts to WebP at build time.

- `ai-tycoon.png` — screenshot of https://ai-tycoon-wheat.vercel.app/
- `vr33s.png` — screenshot of the Vr33s portfolio (run `npm run dev` on that repo, then capture)

Recommended: ~1600×900 (16:9), PNG. Don't pre-compress — the build does it.
A missing import is a build error, not a silent fallback.
